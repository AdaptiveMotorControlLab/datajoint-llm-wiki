## Summary

The DataJoint tutorials index organizes learning into four paths: New to DataJoint (basics 1-5 + University example), Building Production Pipelines (computation, object storage, distributed), Domain-Specific Applications (neuroscience: calcium imaging, electrophysiology, Allen CCF), and Extending DataJoint (custom codecs, JSON types, SQL comparison). Quick start shows minimal working pipeline in ~20 lines.

## Key Claims

- Quick start: `pip install datajoint`, configure credentials, define tables, insert, populate — functional in ~20 lines
- Four structured learning paths with explicit prerequisites and time estimates
- DataJoint Elements (separate project) provides production-ready neuroscience pipelines — not tutorials
- Domain tutorials cover calcium imaging, electrophysiology, and brain atlas ontology
- All tutorials use local MySQL via Docker that resets between sessions

## Key Quotes

> "Choose your learning path based on your goals — each path has prerequisites and suggests next steps beyond the tutorials."
